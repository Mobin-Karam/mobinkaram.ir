# Agent integration

This directory contains portable, assistant-neutral skills used by agents working on Moshaver.

## Canonical instructions

1. `../AGENTS.md` — repository-wide engineering contract.
2. `.agents/skills/*/SKILL.md` — reusable agent skills.
3. `.github/instructions/` — scoped implementation instructions.
4. `.github/prompts/` — reusable task prompts.

## Graphify

Graphify is the preferred first navigation layer for architecture and impact discovery. The project skill is documented in `.agents/skills/graphify/SKILL.md`.

Agents must still inspect the actual source files they modify.
