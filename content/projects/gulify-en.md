An online flower shop built with Next.js and Tailwind CSS. This project includes integration with the Bale messenger for order placement, responsive design, and optimized user experience.

## Features

- Modern, minimal UI
- Bale messenger integration for order placement
- Responsive design for mobile and desktop
- Smooth animations with Framer Motion
- Reusable components

## Technologies

- Next.js 14
- Tailwind CSS
- Server Actions
- Shadcn UI
- Framer Motion
